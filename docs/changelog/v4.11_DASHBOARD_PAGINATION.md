# v4.11 — Dashboard pagination (Conversations & Request History)

## Summary

- **Request History:** Uses existing `GET /proxy/query_db` `offset` and response fields `total_count`, `offset`, `count`. Dashboard adds Previous/Next and a “Showing *a–b* of *n*” line; **Load** resets to the first page. Default sort for the tab is `timestamp_received` descending.
- **Conversations:** New `GET /proxy/conversation_sessions` returns paginated **session** summaries (grouped `session_id`, excluding all-empty-prompt warmup sessions). Opening a session loads the full thread via `GET /proxy/query_db?session_id=…&limit=500&sort_by=timestamp_received&sort_order=asc` (same field projection as before).
- **`session_id=no-session`:** `query_db` treats the literal `no-session` as “NULL or blank `session_id`”, matching the dashboard bucket for requests without a session id.

## Files

- `src/proxy_endpoints.py` — `conversation_sessions`; `query_db` filter for `no-session`
- `static/dashboard/index.html`, `app.js`, `app.css` — pager UI and wiring
- `tests/test_admin_dashboard.py` — coverage for new endpoint and `query_db` pagination metadata
