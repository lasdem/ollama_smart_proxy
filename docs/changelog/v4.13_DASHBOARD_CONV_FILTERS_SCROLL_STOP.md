# v4.13 — Conversations filters, scroll fix, Request History actions

## Summary

- **Conversations filtering:** The Conversations tab now supports Model and IP filters, mirroring Request History semantics. `GET /proxy/conversation_sessions` accepts `model` (prefix match; `*` wildcard) and `ip_address` (exact, or `*` for partial). Rows are filtered before grouping, so only sessions with matching turns are listed. Changing a filter or clicking Refresh resets to the first page.
- **Thread auto-scroll fix:** A conversation you are viewing no longer jumps to the bottom when a *different* conversation is streaming. `showSessionThread` now only auto-scrolls when the open thread is explicitly (re)opened or when that thread itself is actively streaming. Background list refreshes re-render without scrolling.
- **Request History "Stop" confusion:** The green `finish_reason` badge (e.g. `stop`) shared the same solid green as action buttons and looked clickable. `.finish-reason` badges are now outlined, non-interactive labels (fix applies to both Request History and the Conversations thread). Real Stop/Cancel actions were added to Request History rows, shown only for active requests (`processing` → Stop, `queued` → Cancel); completed/error/failed rows get no action button.
